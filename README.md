# 推し広報アプリ「ぼくれぽーと」
数行では語り尽くせない愛を「ぼくだけのれぽーと」として記録するアプリです。

## 公開URL
準備中（近日公開予定）

## 使用方法
1. 「じょうほうをにゅうりょくしてね▼」部分の情報を入力してください。
2. アプリケーション下部の「れぽーとにかきのこす」をクリックしてレポートを作成後、「だうんろーど」ボタンをクリックすると作成した画像をダウンロードすることができます。
3. また、「えっくすでぽすと」をクリックすることで、先ほど作成した「ぼくのれぽーと」を気軽に共有することも可能です！

## アプリを作った理由
映画、アニメ、漫画、ゲーム、小説・・・・・・物語性のあるエンターテインメント作品が大好きだけど、SNSの文字数じゃとても愛を語り切れない！
でも大好きな作品は語りたい！素晴らしさを気軽に共有したい！
そんな気持ちからアプリケーションを作成しました。
気軽に自分だけの「れぽーと」を作って、誰かと楽しく分かち合えますように。

## できること
- 「映画」「アニメ」「漫画」「ゲーム」「小説」のおすすめポイントを入力し、「ぼくだけのれぽーと」を作成できます！
- 作成した画像はダウンロードすることができ、SNSで共有することができます！
- 作成画像は背景をカスタマイズすることができ、紹介作品の雰囲気に合わせた画像作成を楽しむことが可能です！

## 注意事項
- 愛する作品を共有するアプリです。作品の批判はお控えください。
- 画像はご自身で権利を有するもの、または利用許可のあるものをご使用ください。
